# Liminal 84

A multiplayer horror roleplaying game set in Pine Grove, Oregon, in 1984, where the supernatural is real and nobody talks about it.

This repository hosts the Windows client releases. Download the latest `Liminal84-b*.zip` from [Releases](../../releases), unzip it and run `liminal84_game.exe`. The game updates itself when a new build is published.

Official server: `liminal.boring.quest:28484` (Discord sign-in).
