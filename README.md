## What it is

A serious roleplay server in the dark. You play a persistent character in a forested town with a river, a lake and one rural road in and out. You talk to other people in character, and the story is made by players and staff, not scripted quests.

- **Proximity is everything.** Whisper, talk and yell each carry a different distance. Only people close enough hear you.
- **Text only.** There is no voice chat, ever.
- **Restraint over shocks.** Dread comes from what is withheld: darkness, silence, things half-seen.
- **Characters last.** They are separate from your account, and death and loss matter.
- **1984.** No smartphones, no internet. Payphones, cassettes, CB radio, typewriters.

## Install

1. Download the zip from the [latest release](https://github.com/DefenderVex/liminal84_client/releases/latest).
2. Unzip it anywhere you like.
3. Run `liminal84.exe` and sign in with Discord.

You only do this once. After that the game updates itself when it starts, downloading just the parts that changed.

## Playing

| | |
| --- | --- |
| **Sign in** | Discord. The game opens your browser to confirm, then returns. |
| **Characters** | Three slots. Pick a name and a description; staff handle backgrounds. |
| **Move** | `W` `A` `S` `D`, `Space`, `Shift` |
| **Chat** | `Y` to type. The range ring on the ground previews who will hear you. |
| **Use** | `E` on doors and light switches |
| **Menu** | `Esc` |

All keys can be rebound in settings, and there is a UI size option.

## Requirements

- Windows 10 or 11, 64-bit
- A GPU with Vulkan support
- A Discord account

If the game will not start or will not update, open an [issue](https://github.com/DefenderVex/liminal84_client/issues) and say what the boot screen showed.
